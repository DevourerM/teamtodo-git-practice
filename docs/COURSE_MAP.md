# Course Map - 教材与仓库对应关系

| 教材阶段 | GitHub 对象 | 你要做什么 |
|---|---|---|
| 环境准备 | Code | Clone 仓库并运行测试 |
| 主线实战 1 | Issue #1 | 创建 `feature/task-priority` |
| 第一次 PR | Pull requests | 把 Issue #1 的分支提到 `main` |
| 第二次独立练习 | Issue #2 | 显示优先级 |
| Code Review | Issue #3 / PR | 根据 Reviewer 反馈继续修改原 PR |
| CI | Issue #4 / Actions | 故意让测试失败，再修复 |
| 冲突 | Issue #5 | 使用 `scripts/prepare_conflict_lab.ps1` 或手动制造冲突 |
| 独立验收 | Issue #6 | 完整实现 `search()` 并走完协作流程 |

如果教材中的画面与 GitHub 当天 UI 有轻微差异，请优先寻找相同的文字入口：`Code`、`Issues`、`Pull requests`、`Actions`、`Files changed`、`Checks` 等。
